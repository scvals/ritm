# Ритм — личный трекер

Работает в браузере и как отдельное приложение: на компьютере открывается в своём окне с иконкой, на телефоне — с главного экрана. Работает и без интернета.

## Как выложить на GitHub (один раз, ~10 минут)

1. Зарегистрируйся на https://github.com (бесплатно).
2. Нажми **«+» → New repository**. Название: `ritm`. Тип: **Public**. Нажми **Create repository**.
3. На странице репозитория нажми **uploading an existing file** и перетащи в окно **все файлы из этой папки вместе с папкой `icons`**. Нажми **Commit changes**.
4. Открой **Settings → Pages**. В «Branch» выбери `main` и папку `/ (root)`, нажми **Save**.
5. Через 1–2 минуты трекер откроется по адресу `https://ТВОЙ-ЛОГИН.github.io/ritm/`.

## Как установить как приложение

- **Компьютер (Chrome или Edge):** открой адрес, нажми значок «Установить» справа в адресной строке (или меню ⋮ → «Установить Ритм»). Появится ярлык на рабочем столе, трекер откроется в отдельном окне.
- **Android (Chrome):** меню ⋮ → «Установить приложение».
- **iPhone (Safari):** кнопка «Поделиться» → «На экран „Домой“».

## Облачная синхронизация (приватно)

В трекере: **Настройки → Облачная синхронизация**. Создаёшь токен GitHub по готовой ссылке (галочка «repo»), вставляешь — трекер сам создаст **приватный** репозиторий `ritm-data` и будет хранить там данные. Этот репозиторий видишь только ты; каждое сохранение — отдельная версия в истории.

Чтобы подключить телефон, нажми на компьютере «Ссылка для другого устройства» и открой её на телефоне. В ссылке твой токен — никому её не пересылай.

Про сам сайт: на бесплатном тарифе GitHub Pages работает только из публичного репозитория, поэтому код трекера и адрес сайта открыты. Но любой, кто откроет адрес, увидит **пустой** трекер — твои записи хранятся на твоих устройствах и в приватном `ritm-data`, без твоего токена до них не добраться.

## Перенос из старой версии

В старом трекере: Настройки → «Скачать резервную копию». В новом: Настройки → Резервная копия → «Загрузить из копии».

## Обновление

Чтобы обновить трекер, загрузи новые файлы в тот же репозиторий поверх старых. Данные не пострадают.
